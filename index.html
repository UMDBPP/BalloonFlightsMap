Control Info:

  • Right-click and drag to control map pitch and rotation
  • Open the drawing tool (top-left) and use the point tool (the dot) to place custom launch locations. If the predict line doesn't appear, try clicking "Fetch Predicts"
  • Open the layer switcher (hover over top-right) and click 2D or 3D under "Map Dimensions" to toggle compatible layers between 2D and 3D
  • Layer features on the map can be clicked to display a popup showing their properties

Known Issues:

  • This about dialog is not styled and does not have enough/any information about the map
  • This list has not been filled out yet
  • Flight KML/GeoJSON files have not been cleaned up or filtered or anything in any way
  • Some of the KML/GeoJSON files use feet for altitude, which is not correctly accounted for here
  • Ground track colors are not consistent between 2D and 3D
  • KML files are currently far better supported than GeoJSON files (though GeoJSON files can at least be displayed on the map to some degree)
